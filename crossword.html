      How To Play

      Error check mode

      If you want to know whether you’ve typed incorrect entries, use the Error Check mode. You can find it under Settings at the top right of the puzzle. When this option is turned on, incorrect letters are shown with a diagonal line across them.

      Score

      • Find a word? 10 points
      • Reveal an entire word? 0 points
      • Reveal a letter? - 1 point per letter

      Finish the puzzle correctly within the 15 minutes target time and earn a bonus of 15 points for every minute you finish early.

      Start again

      Use the Start again option to reset the entire grid. The empty grid will be displayed and the clock will be set back to zero.

      Print

      Use the Print menu to print the empty puzzle, the grid with the letters filled in so far, or the grid with the entire solution.
